# 简历审核报告模板

```md
# 简历审核报告

## 审核范围

- 审核时间：<填写日期>
- 审核目录或文件范围：<填写路径或范围>
- 审核标准：筛选具有 5 年以上交通行业相关开发或产品经验的候选人

## 结果汇总

- 简历总数：<N>
- 符合条件：<A>
- 不符合条件：<B>
- 人工审核：<C>

## 符合条件

### <候选人姓名或文档名>

- 文档路径：<path>
- 角色类型：<开发 / 产品 / 混合>
- 可确认相关年限：<X 年 Y 个月>
- 结论：符合
- 依据：<用 2 到 5 句话概括交通行业属性、职责类型、年限来源>

## 不符合条件

### <候选人姓名或文档名>

- 文档路径：<path>
- 角色类型：<开发 / 产品 / 混合 / 不明确>
- 可确认相关年限：<X 年 Y 个月 / 无法确认>
- 结论：不符合
- 原因：<明确写出不符合原因，可多条，但应合并成一段清晰说明>

## 人工审核

### <候选人姓名或文档名>

- 文档路径：<path>
- 角色类型：<开发 / 产品 / 混合 / 不明确>
- 当前可确认相关年限：<X 年 Y 个月 / 无法确认>
- 结论：人工审核
- 触发条件：<客户信息缺失 / 项目时间模糊 / 多个项目重叠异常 / 交通行业属性不明确 / 职责描述过短 / 其他>
- 说明：<写清楚当前证据、卡点和建议补充的信息>

## 审核结论说明

- “符合”表示已有足够证据确认候选人具有 5 年以上交通行业相关开发或产品经验。
- “不符合”表示已有足够证据确认候选人不满足条件。
- “人工审核”表示存在较强相关性或明显信息缺口，但当前证据不足以做最终确定。
```
