# 参考文档格式观察

本文件总结 `assets/reference-template.docx` 的结构特征，供生成脚本和后续维护使用。

## 整体结构

参考文档大致由以下部分组成：

1. 封面页
2. 文档修订历史
3. 目录页
4. 正文多级标题章节
5. 多个信息表格

## 页面设置

- 纸张：A4 纵向
- 上边距：约 1.27 cm
- 下边距：约 1.27 cm
- 左边距：约 2.12 cm
- 右边距：约 1.95 cm
- 页眉距离：约 1.50 cm
- 页脚距离：约 1.24 cm

## 主要段落样式

- `-Section-Central`
  - 用于封面主标题
  - 居中
  - 粗体
  - Times New Roman，约 20pt
- `-H-body`
  - 用于“文档修订历史”等章节型标题
  - 两端对齐
  - 东亚字体接近 `PMingLiU`
  - 约 12pt
- `-body`
  - 用于目录页标题
  - 居中加粗
- `Heading 1`
  - 章标题
  - 粗体
  - Times New Roman，约 15pt
- `Heading 2`
  - 节标题
  - 粗体
  - 两端对齐
  - 约 14pt
- `Heading 3`
  - 小节标题
  - 粗体

## 目录样式

- 使用 `toc 1`、`toc 2`、`toc 3`
- 带页码
- 依标题级别缩进

## 表格特征

- 修订历史表使用 Word 内建样式，接近 `格线表格 4 - 辅色 52`
- 业务表格大量使用 `Normal Table`
- 常见形式：
  - 2 列信息表
  - 3 列同步/说明表
  - 5 列状态控制表
- 表头通常加粗，边框完整

## 内容表现规律

- 章节结构偏正式政府/企业技术文档风格
- 标题层级清晰，基本为三级
- 多使用“说明 + 表格”的方式组织内容
- 适合系统架构、数据模型、集成设计、部署设计、安全设计等主题

## 生成策略建议

优先采用以下策略以逼近参考文档观感：

1. 用 `python-docx` 打开 `reference-template.docx`
2. 保留模板样式、主题、节设置
3. 清空正文节点后重新插入内容
4. 正文标题尽量复用 `Heading 1/2/3`
5. 封面优先使用 `-Section-Central`、`-H-body`、`-body`
6. 表格优先套用模板已有样式；不存在时再退回脚本内建边框和表头格式
