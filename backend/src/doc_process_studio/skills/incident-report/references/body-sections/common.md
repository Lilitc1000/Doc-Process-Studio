# Incident Body Generation Common Reference

- 目标：生成可直接写入事故报告正文的内容，语言准确、事实一致、便于复盘。
- 约束：严禁编造；若信息不足，使用保守表达并保持可执行性。
- 风格：短句优先，避免空泛形容词；结论需能被上下文支撑。
- 时间格式：优先 `DD/MM/YYYY HH:MM`；仅有时间时可用 `HH:MM`。
- 时间线原则：按先后顺序，突出“事件 -> 处理 -> 结果/证据”。
- 影响评估：同时体现技术影响与业务影响，避免只写其一。
- 根因分析：区分触发原因与深层根因，避免互相重复。
- 后续动作：建议输出可执行、可验证、可追踪的动作。
