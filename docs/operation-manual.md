# Doc Process Studio 用户手册

欢迎使用 Doc Process Studio —— 您的 AI 文档处理助手。本手册将帮助您快速了解系统的各项功能，并指导您完成日常操作。

---

## 1. 系统简介

Doc Process Studio 是一个智能文档处理平台，帮助您更高效地完成以下工作：

- **与 AI 对话** — 随时提问，获取智能回复，支持上传文件进行针对性分析
- **管理事故报告** — 从创建到审批的完整流程管理，AI 辅助生成专业报告正文
- **生成专业文档** — 基于项目代码自动生成架构设计文档、审核简历等

---

## 2. 登录与账号

### 2.1 注册账号

1. 打开系统首页，点击「注册」
2. 输入您想使用的用户名和密码
3. 点击注册，完成后自动跳转到登录页

### 2.2 登录

1. 在登录页输入用户名和密码
2. 点击登录，进入系统首页

### 2.3 修改个人信息

登录后，点击右上角的头像，在下拉菜单中可以：

- **查看和编辑个人资料** — 修改用户名等信息
- **修改密码** — 输入当前密码和新密码即可完成修改
- **退出登录** — 安全退出当前账号

> 系统会在您登录 15 分钟后自动过期，届时会自动为您续期，无需重新登录。如果超过 7 天未使用，则需要重新登录。

---

## 3. 首页导航

登录后进入首页，您会看到三个功能入口：

| 入口 | 说明 |
|------|------|
| **对话** | 进入 AI 对话界面，与助手交流或处理文档 |
| **事故报告** | 进入事故报告管理模块 |
| **设置** | 配置 AI 模型偏好 |

在任何子页面，点击左上角的首页按钮即可返回首页。

## 4. AI 对话

AI 对话是系统的核心功能，您可以通过自然语言与 AI 助手交流，获取信息、分析文档或完成各种任务。

### 4.1 开始对话

1. 在首页点击「对话」，或从侧边栏选择已有会话
2. 在底部输入框中输入您的问题或需求
3. 按 Enter 发送，AI 会实时流式回复

### 4.2 会话管理

您的对话以「会话」为单位组织，左侧边栏显示所有会话列表。

| 操作 | 方法 |
|------|------|
| 新建会话 | 点击侧边栏的「新建会话」按钮 |
| 切换会话 | 在侧边栏点击目标会话 |
| 修改会话标题 | 点击会话标题旁的编辑图标 |
| 删除会话 | 点击会话旁的删除图标 |

### 4.3 上传文件

您可以在对话中上传文件，AI 会读取文件内容并据此回答问题。

- 支持的文件类型：PDF、Word、Excel、PPT 等常见文档格式
- 点击输入框旁的附件按钮选择文件
- 上传后，AI 会自动理解文件内容

### 4.4 使用 Skill（技能）

Skill 是系统内置的专业能力，可以让 AI 在特定领域表现更专业。在输入框中，您可以选择激活某个 Skill：

| Skill | 适用场景 |
|-------|---------|
| **文档助手** | 上传文档后需要快速阅读、提炼、总结或答疑 |
| **项目架构文档生成** | 需要根据项目代码自动生成专业的架构设计 Word 文档 |
| **简历交通行业审核** | 需要批量审核候选人简历，筛选交通行业经验 |

选择 Skill 后，AI 会使用该领域的专业知识和工具来处理您的请求。

### 4.5 消息操作

对 AI 的回复，您可以进行以下操作：

- **复制** — 一键复制回复内容
- **编辑** — 修改您之前发送的消息并重新生成回复
- **重新生成** — 让 AI 重新生成当前回复
- **查看执行过程** — 如果 AI 调用了工具，可以查看完整的执行链路

## 5. 事故报告管理

事故报告模块帮助您完成事故报告的创建、编辑、审批和归档，并提供 AI 辅助生成报告正文的功能。

### 5.1 角色说明

系统中不同角色拥有不同的操作权限：

| 角色 | 能做什么 |
|------|---------|
| **报告人** | 创建报告、编辑自己的报告、提交审核 |
| **审核人** | 审核待审核报告、分配处理人、查看所有报告 |
| **处理人** | 查看分配给自己的报告、更新处理进度、关闭报告 |
| **管理员** | 所有操作权限 + 角色分配 + 系统配置 |
| **观察者** | 查看报告列表和详情（只读） |

> 您的角色由管理员分配。如需更高权限，请联系管理员。

### 5.2 创建事故报告

1. 在首页点击「事故报告」，进入报告列表页
2. 点击「新建报告」
3. 按照向导步骤填写事故信息：
   - **基本信息** — 事故标题、发生时间、严重级别等
   - **详细描述** — 事故经过、影响范围、根本原因、后续跟进
   - **时间线** — 按时间顺序记录关键事件节点
4. 填写完成后，选择「保存草稿」或「提交审核」

### 5.3 AI 辅助生成报告正文

填写完基本信息后，您可以让 AI 帮您生成专业的报告正文，节省撰写时间。

#### 一键生成（快填模式）

点击「AI 一键生成」按钮，AI 会根据您填写的基本信息，一次性生成完整的报告正文，包括：

- 事故描述
- 时间线
- 影响分析
- 根本原因
- 后续跟进

#### 分段生成

如果您只想生成某个段落，点击对应段落旁的「AI 生成」按钮即可。可选的段落包括：

- 描述（description）
- 时间线（timeline）
- 影响分析（impact）
- 根本原因（root_cause）
- 后续跟进（follow_up）

> AI 生成的正文为英文，符合国际事故报告的通用格式要求。生成后您可以查看和确认内容。

### 5.4 报告状态与流转

一份事故报告从创建到关闭，会经历以下状态变化：

```
草稿 → 待审核 → 已批准 → 处理中 → 已关闭
         ↓                    ↑
       已驳回 ──修改后重新提交──┘
                              │
         已关闭 ────重新打开───┘
```

| 状态 | 含义 | 您可以做什么 |
|------|------|-------------|
| **草稿** | 报告正在编写中 | 编辑内容、提交审核 |
| **待审核** | 已提交，等待审核人审批 | 等待审核结果 |
| **已批准** | 审核通过，等待处理 | 等待分配处理人 |
| **已驳回** | 审核未通过 | 修改后重新提交 |
| **处理中** | 处理人正在跟进 | 更新处理进度 |
| **已关闭** | 事故已处理完毕 | 可重新打开（如需跟进） |

### 5.5 审核报告（审核人/管理员）

1. 在报告列表中筛选「待审核」状态的报告
2. 进入报告详情页，查看报告内容
3. 选择「批准」或「驳回」
   - 批准：报告进入「已批准」状态，可指派处理人
   - 驳回：报告退回给报告人修改

### 5.6 导出报告文档

在报告详情页，点击「生成预览」可以生成 Word 或 PDF 格式的正式报告文档，用于存档或分发。

### 5.7 评论与审计

- **评论** — 在报告详情页可以添加评论，与团队成员沟通
- **审计日志** — 系统自动记录报告的所有操作（状态变更、内容修改等），可在详情页查看完整审计记录

### 5.8 统计分析

在事故报告模块的「统计分析」页面，您可以查看：

- **月度概览** — 报告数量、状态分布等汇总数据
- **趋势图** — 按天展示的报告数量变化趋势

### 5.9 角色权限管理（管理员）

管理员可以在「角色权限管理」页面：

- 查看所有用户及其当前角色
- 为用户分配新角色或撤销现有角色
- 查看各角色对应的权限详情

## 6. 系统设置

在首页点击「设置」，您可以配置以下偏好：

| 设置项 | 说明 |
|--------|------|
| **生成模型** | 选择 AI 生成文档时使用的模型，不同模型在速度和质量上有所差异 |
| **重排序模型** | 选择 AI 检索信息时使用的重排序模型，影响上下文的相关性排序 |

> 模型选择会自动保存，下次使用时无需重新设置。

## 7. 常见问题

### 登录相关

**Q: 忘记密码怎么办？**
A: 请联系管理员重置密码。系统目前不支持自助找回密码。

**Q: 登录后一段时间操作提示未登录？**
A: 系统会自动为您续期。如果长时间未操作（超过 7 天），需要重新登录。

### 对话相关

**Q: AI 回复速度慢怎么办？**
A: 回复速度取决于 AI 模型的处理能力。您可以在「设置」中尝试切换不同的生成模型。

**Q: 上传的文件有大小限制吗？**
A: 文件附件会在系统中保留 7 天，过期后自动清理。如需长期保存，请及时下载。

**Q: AI 的回答不准确怎么办？**
A: 您可以尝试：1）更具体地描述您的需求；2）上传相关文件提供更多上下文；3）使用对应的 Skill 获得更专业的回答。

### 事故报告相关

**Q: 提交审核后还能修改吗？**
A: 报告在「待审核」状态下无法修改。如果审核人驳回，您可以修改后重新提交。

**Q: AI 生成的正文可以编辑吗？**
A: AI 生成的内容会回填到表单中，您可以在此基础上进一步修改和完善。

**Q: 如何查看谁处理了我的报告？**
A: 在报告详情页的审计日志中，可以查看完整的操作记录，包括处理人信息。

**Q: 已关闭的报告还能重新打开吗？**
A: 可以。管理员和处理人可以重新打开已关闭的报告进行后续跟进。
